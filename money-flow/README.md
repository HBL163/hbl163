# 中国货币与资金流向全景监测

按月更新的中国宏观货币数据看板，追踪货币来源、持有部门、融资行业、实际用途与经济效果。

## 当前状态
- 已建立静态 HTML 看板和月度报告目录结构。
- 已准备每月定时构建与 GitHub Pages 发布工作流。
- 数据模板和校验器已建立。
- **当前不伪造数据**：官方数据采集与交叉核验接通前，页面明确显示“等待官方数据接入”。

## 分析原则
1. 区分存量、当期增量、累计增量、同比和环比。
2. 贷款投向不等于资金最终用途。
3. 存款增加不等于收入、利润或净财富增加。
4. M2 是货币存量统计，不是逐笔资金流水。
5. 不把不同统计口径直接相加。
6. 每个数据点必须包含统计期、单位、发布日期和官方来源。

## 官方来源
- [中国人民银行](https://www.pbc.gov.cn/)
- [国家统计局](https://www.stats.gov.cn/)
- [财政部](https://www.mof.gov.cn/)
- [国家金融监督管理总局](https://www.nfra.gov.cn/)

数据不足或无法识别的环节会明确标注，不用推测冒充事实。
